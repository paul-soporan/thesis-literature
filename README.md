# Thesis Literature

This repository collects literature for a thesis on formally verified,
resource-aware synthesis of hybrid sorting policies.

## Layout

- [`literature_notes.md`](literature_notes.md) — annotated notes grouped by
  research theme, including each source’s relevance to the thesis.
- [`references.bib`](references.bib) — BibTeX entries for cited sources; citekeys
  in the notes correspond to entries here.
- [`papers/`](papers/) — source PDFs, grouped by topic:
  - `sorting/` — hybrid and adaptive sorting algorithms
  - `autotuning/` — empirical sorting autotuning and algorithm selection
  - `formal-verification/` — verified sorting implementations
  - `synthesis/` — program synthesis and sorting networks
  - `resource-analysis/` — symbolic cost, resource, and hardware models
